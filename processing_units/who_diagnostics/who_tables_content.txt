What who_tables.h Contains1. Diagnostic Data StructuresLMS_Params: Output structure holding the active $L, M, S$ coefficients used during runtime computation.LMS_Entry: Data structure holding length (cm) and corresponding $L, M, S$ values stored in flash memory.2. WHO Weight-for-Length Lookup Datasets (PROGMEM)WHO_WLZ_BOYS[]: 131 calibrated entries covering recumbent lengths from 45.0 cm to 110.0 cm in 0.5 cm increments for male infants.WHO_WLZ_GIRLS[]: 131 calibrated entries covering recumbent lengths from 45.0 cm to 110.0 cm in 0.5 cm increments for female infants.Embedded Coefficients:$L$ (Lambda / Box-Cox Power Transformation): Accounts for skewness in infant weight distribution.$M$ (Mu / Median Weight in kg): The expected 50th centile weight for that exact body length.$S$ (Sigma / Coefficient of Variation): Measures data spread and standard deviation boundaries.3. High-Speed $O(1)$ Interpolation Engine (getInterpolatedLMS)Boundary Clamping: Restricts input lengths to the valid WHO range ($45.0\text{ cm} \le \text{Length} \le 110.0\text{ cm}$).Direct Index Mapping: Calculates table positions mathematically via $\text{Index} = \frac{\text{Length} - 45.0}{0.5}$ without loops or array scans.Zero-SRAM Flash Access: Reads values directly from flash storage using pgm_read_float(), keeping RAM usage at $0\text{ KB}$.Two-Point Linear Interpolation: Calculates exact continuous $L, M, S$ values for sub-millimeter measurements falling between $0.5\text{ cm}$ table steps:$$\text{Value} = P_1 + \text{Factor} \cdot (P_2 - P_1)$$
